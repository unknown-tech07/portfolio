# Ozzy Hernandez — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive styling
- `script.js` — mobile navigation, reveal animations, year, and copy-email button

## Before publishing
1. Open `index.html`.
2. Replace `your.email@example.com` with your real professional email.
3. Add your own project screenshots if you want visual proof of your work.
4. Review the About/Experience wording and adjust anything that is no longer accurate.

## Run locally
Double-click `index.html`, or open the folder with VS Code and use a local server extension.
